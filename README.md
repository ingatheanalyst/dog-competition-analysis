# dog-competition-analysis (Анализ данных кинологических соревнований по IGP)

## О проекте
Данный проект представляет собой исследовательский анализ данных соревнований по кинологическому спорту в дисциплине IGP за 2024-2026гг.
Цель анализа - выявить закономерности в результатах выступающих собак, сравнить успешность разных пород и проанализировать динамику результатов во времени.

## Данные
Данные взяты из открытого источника https://www.igpsport.pro и представлены в виде дву связанных таблиц:
* "dogbase.csv" - справочник участников (ID, кличка, порода, проводник, город).
* "Champ.csv" - результаты выступлений (ID, баллы за разделы A, B, C, итоговый балл,качественная оценка, год).

## Инструменты
* **SQL (SQLite)** - для извлечения и агрегации данных.
* **Python (Pandas, Matplotlib/Seaborn)** - для обработки данных и визуализации.

## Результаты (SQL-запросы)
Все запросы находятся в файле "queries.sql". В рамка проекта были решены следующие задачи:
Запрос 1: Топ 5 за 2026г
Запрос 2: Как менялся средний итоговый балл и количество участников по годам?
Запрос 3: Топ-3 собаки по итоговым баллам в каждом году
Запрос 4: Динамика результатов собак (разница с предыдущим годом)
Запрос 5: Собаки, с сильным следом (А) и защитой (С), но слабым послушанием (В)
Запрос 6: Статистика по породам (средний балл, лучший балл, худший балл)
Запрос 7: Самая перспективная порода в IGP
Запрос 8: Кореляция следа и остальных разделов
Запрос 9: Вывести всех собак чей результат от года к году упал на 10% и более
Запрос 10: Вывести список от самых стабильных к менее стабильным по общему баллу

## Как запустить
1. Импортируйте файлы "dogbase.csv" и "Champ.csv" в SQLite.
2. Выполните запросы из файла "queries.sql".
