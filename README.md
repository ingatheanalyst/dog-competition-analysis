# Портфолио аналитика данных (Инга Кузнецова)

В этом репозитории собраны мои проекты, демонстрирующие навыки работы с данными, SQL, Python и продуктовой аналитики.

# Мои проекты:

### 1. [Анализ данных кинологических соревнований (SQL)](./sql-dog-project/)
*   **Задача:** Исследовать данные соревнований по IGP за 3 года, выявить закономерности в результатах пород.
*   **Стек:** SQL (SQLite), Python (Pandas), ETL.
*   **Что сделано:** Очистка данных, написание сложных запросов (JOIN, CTE, оконные функции), анализ динамики и корреляций.

### 2. [Продуктовая аналитика E-commerce (Воронки, A/B-тесты)](./ecommerce-product-analytics/)
*   **Задача:** Оценить конверсию пользователей на разных этапах, проверить эффективность новой фичи через A/B-тест, рассчитать Retention.
*   **Стек:** SQL, Python (SciPy, Pandas).
*   **Что сделано:** Построение воронки продаж, расчет статистической значимости (p-value), когортный анализ.
